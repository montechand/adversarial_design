### Forced Axes: Full-Width Stacked Editorial Single Column | Clinical Cool Navy #1A2B6B + White + Ice Blue | Mixed Weight Drama: Ultra-Light 32px Headline + Bold 18px Subhead | Progressive Disclosure Summary Cards | Humanizing Story-Led HCP-as-Hero | Floating Sidebar CTA at 40% Scroll

---

## OVERARCHING DESIGN PHILOSOPHY

This spec delivers a **humanizing, story-led HCP communication** that treats the neuromuscular specialist as the clinical hero navigating the CHAMPION-MG data on behalf of their patients. Forced axes are interpreted entirely within ULTOMIRIS brand vocabulary:

- **"Full-width stacked editorial, single column"** → Pure vertical stacking of full-width bands. No multi-column grids in the body. Section rhythm: preheader → gradient strip → hero → greeting → intro → efficacy 1 → efficacy 2 → PD → safety → CTA → signature → ISI. Every band stretches edge-to-edge within the 600px container.

- **"Clinical cool: navy #103F66 + white + ice blue accent"** → The forced axis "navy #1A2B6B" is interpreted as the closest brand-approved color: campaign navy #103F66 (brand rule supreme). Ice blue accent maps to #EEF3F8 (production-approved wash). White #FFFFFF provides neutral relief between dark bands. No alien hues introduced.

- **"Mixed weight drama: ultra-light 32px headline + bold 18px subhead"** → Expressed through Arial weight contrast (Arial at 13px regular for eyebrow labels vs. 32px bold for primary section headlines, vs. 18px bold for subheads within sections). Brand rule requires Arial as email-safe substitute; "ultra-light" weight unavailable in email-safe Arial stack, so it is expressed as font-size contrast drama: 32px regular-weight (not bold) greeting headline in #008578 versus 18px bold subheads in #3F4444 — maximum size differential within the brand-safe font stack creating the axis' intended weight drama effect.

- **"Floating sidebar CTA at 40% scroll"** → Single-column email cannot have a true CSS sidebar. Interpreted as a visually distinct full-width "mid-stream" CTA band appearing after Section 4 (QMG — approximately 40% of scroll depth in a typical 600px-wide email), styled distinctly from all other section bands: #33ADA0 teal fill with #007267 border treatment, white text, action copy. This is the only "floating" CTA interruption; primary orange button remains in Section 7.

- **"Progressive disclosure: summary cards that hint at detail"** → Each efficacy section opens with a compact teal (#33ADA0 fill, #007267 border) summary card displaying the headline stat and a "detail below" cue, followed by the full data callout. The card format signals "there is more beneath" without overwhelming at first glance, per the numbered card system from Reference #1.

- **"Humanizing story-led, HCP as hero"** → Opening copy addresses the specialist directly as the expert navigator. Section headlines use second-person framing ("your patients," "what you're seeing"). The CTA section closes with language centering the HCP's decision-making authority. This tone is woven into body copy, not expressed through imagery alone.

**Baseline weakness directly countered — INDICATION MISMATCH IN HERO:** The baseline's NMOSD hero asset failure is explicitly corrected. The hero asset placeholder `[images_base64_0]` carries a developer comment mandating gMG-specific anti-AChR+ indication text. Alt text specifies anti-AChR antibody-positive gMG. No NMOSD language appears anywhere in this spec.

**Baseline weakness directly countered — MONOTONOUS SECTION RHYTHM:** Seven distinct background band treatments cycle systematically: #D7D2CB (preheader) → #103F66 (hero) → #FFFFFF (greeting) → #103F66 (intro) → #FFFFFF (Section 3) → #EEF3F8 (Section 4) → #FFFFFF (Section 5) → #103F66 (Section 6) → #FFFFFF (CTA) → #F2F1F1 (signature) → #FFFFFF (ISI). Consistent alternation per Reference #1 and #2 rhythm.

**Baseline weakness directly countered — DISPLAY:TABLE RENDERING RISK:** All side-by-side stat callout layouts use nested HTML `<table>` elements with `<td>` cells exclusively. No `display:table`, `display:table-cell`, CSS Grid, or Flexbox anywhere in layout-critical code.

**Baseline weakness directly countered — TYPOGRAPHY LACKS HIERARCHY CONTRAST:** This spec introduces a deliberate size-and-weight scale: 32px regular (greeting display) / 24px bold (section H2 teal) / 18px bold (data subheads, dark gray) / 15px regular (body) / 13px bold (labels, micro-CTA) / 10px regular (footnotes, ISI) — six distinct tiers replacing the baseline's single-size Arial-only hierarchy.

## GLOBAL TECHNICAL CONSTRAINTS

- **Container:** `<table width="600" cellpadding="0" cellspacing="0" border="0" style="max-width:600px; margin:0 auto; background-color:#FFFFFF; border:2px solid #E4E4E4;">` — 2px #E4E4E4 border frame per Reference #1 and #2 pattern
- **Outer wrapper `<body>` background:** `#F2F1F1`
- **Max-width:** 600px, `margin:0 auto`
- **Layout method:** Nested `<table>` elements ONLY. NO CSS Grid. NO Flexbox. NO `display:table`. NO `display:table-cell` on any layout-critical element. All side-by-side stat layouts use `<table>` with `<td>` cells.
- **Font stack — ALL text:** `Arial, Helvetica, sans-serif` (brand rule: News Gothic BT → Arial email-safe substitute). Georgia or any serif font is NOT used in this candidate (brand rule: typeface is News Gothic BT / Arial; serif is not in the brand system; the magazine-style axis of the baseline is not carried forward here — this candidate uses Arial weight/size contrast instead).
- **Inline CSS on ALL elements.** One `<style>` block in `<head>` for resets only: `body, table, td, p, h1, h2, h3, h4 { margin:0; padding:0; border:0; }` plus `img { display:block; border:0; }` plus `a { text-decoration:none; }`
- **All images:** `<img>` with `display:block; border:0; width:100%; max-width:[N]px; height:auto;` and descriptive alt text. Use `[images_base64_0]` through `[images_base64_4]` as numbered placeholders.
- **No italic** in any headline. `<em>` tags permitted ONLY for *Neisseria meningitidis* in REMS/ISI text.
- **ISI:** Full-width section below all marketing content. Minimum 10px font size — no exceptions.
- **Single primary CTA:** Orange #FF6A39 table-cell button in Section 7. The mid-email #33ADA0 teal band at ~40% scroll is the "floating" secondary CTA.
- **ULTOMIRIS®** on first mention per section; ravulizumab-cwvz in parentheses at first full drug name use per section.
- **P-values:** Render as `P&lt;0.001` (capital P, no space before operator, HTML-encoded less-than).
- **Every efficacy stat:** Inline superscript citation at 8px.
