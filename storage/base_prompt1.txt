# HTML Email Design Spec — Candidate 2
## "Empowering Split Authority: Hero-Left / Text-Right at 40/60 with Extreme Typographic Scale, Low Density, Warm Credibility Palette"

---

## CONCEPT & DIFFERENTIATION STRATEGY

This spec executes a **persistent hero-left / text-right split column architecture** at a strict 40/60 ratio (240px / 360px) within the 600px content width. Every section maintains this structural DNA. The left column carries one bold visual element per section — a massive numeral, a tight clinical label, or a stark geometric accent block — while the right column carries the headline and terse body copy. This creates a **two-register reading experience**: scanners read the left column vertically (numerals and labels) while deliberate readers engage the right column narrative. This is the polar opposite of the baseline's monotonous heading→paragraph→data-grid→footnote cadence.

**Forced Axis: Hero-left text-right split, 40/60 ratio.** The left column (240px) acts as a persistent visual "spine" — it carries the data hero at extreme scale. The right column (360px) carries copy. This is maintained through Sections 1–7 with section-specific left-column content. The sole deviation is the ISI block (full-width, regulatory requirement) and the REMS panel (full-width per brand rule). The brand-rule exemption for the QMG responder row renders as two equal sub-cells within the right column only.

**Forced Axis: Warm credibility — deep burgundy `#6B1A2A` + warm off-white `#FAF7F2` + antique gold `#B8860B`.** The header is a full-bleed `#6B1A2A` burgundy band. Alternating section left-column backgrounds use `#6B1A2A` (dark) and `#FAF7F2` (warm off-white) to create a chevron-stripe visual rhythm down the spine. Gold `#B8860B` appears exclusively as rule lines, border accents, and the left-column background on Sections 2 and 5. Brand violet `#4B2D8F` is used precisely for headlines, CTA button, data numerals, and callout borders per brand rules. This directly counters the baseline weakness: **"Monotonous section rhythm — every block follows an identical heading → paragraph → data grid → footnote pattern."** The alternating left-column color field creates an immediately distinct visual cadence with no extra content.

**Forced Axis: Geometric sans with extreme size contrast — 48px / 14px.** Left-column hero numerals render at 48px bold in `#4B2D8F` (brand violet, brand rule) on warm off-white, or `#FFFFFF` on burgundy backgrounds. Right-column body copy renders at exactly 14px, `font-weight: 400`, `color: #222222`. This 48:14 ratio produces maximum scale drama within a single section row. No other element in the email approaches 48px except the primary endpoint numeral — which enforces hierarchy at scan speed. System font stack: `Arial, Helvetica, sans-serif` throughout (no external font imports per brand rule). The scale contrast directly counters the baseline weakness: **"System-stack Arial/Helvetica throughout, creating a generic utilitarian feel with no typographic distinction — the rhythm is metronomic."**

**Forced Axis: Hero CTA only, minimal interruption.** A single CTA appears in Section 7 only — a full-width burgundy `#6B1A2A` band at the base of the content column, containing one bold action button in brand violet `#4B2D8F`. No mid-scroll CTA, no repeated buttons, no secondary links styled as buttons. The CTA renders as an unmissable architectural terminus rather than an interruption, using the deepest color in the email to signal finality.

**Forced Axis: Low density — one claim per section, lots of whitespace, ISI below fold.** Each section's right column carries exactly one headline (the primary claim) and one paragraph (maximum 2 sentences, per brand rule). Data numerals and labels in the left column carry the quantitative load. ISI is a completely separate section below a full-width `#E5E7EB` divider at the very bottom. The left-column width naturally limits copy sprawl, enforcing low density.

**Forced Axis: Empowering patient outcomes narrative.** Every right-column headline leads with the clinical outcome benefit first (brand rule: data claim before endpoint name). The framing acknowledges patients behind the data — "your patients with anti-AChR+ gMG" — without using warm conversational tone (brand rule: terse clinical copy).

**Counter to baseline weakness: "Complete absence of imagery — no hero banner, no brand mark in header."** The header band is a full-width `#6B1A2A` burgundy strip containing the ULTOMIRIS logo placeholder `[images_base64_1]` left-aligned and the Alexion AstraZeneca Rare Disease wordmark right-aligned, separated by a `2px solid #B8860B` gold bottom rule. The brand is established in the first 80px of the email.

**Counter to baseline weakness: "No visual header or brand identity presence."** The persistent 240px left-column spine, alternating between `#6B1A2A` and `#FAF7F2`, creates a designed visual identity system that runs the full length of the email — every scroll position shows the brand color architecture.

**Counter to baseline weakness: "CTA button is buried after ~1800px of scrolling content."** The single CTA is placed in a visually distinct terminus band — the darkest element in the lower half — with a full 36px top padding of whitespace above it, pulling the reader's eye as the scroll slows.

## LAYOUT ARCHITECTURE

### Overall Structure

- **Outer wrapper table:** `<table width="100%" cellpadding="0" cellspacing="0" border="0" style="background-color: #EDE8E0;">` — warm greige outer canvas, 100% width
- **Inner content table:** `<table width="600" cellpadding="0" cellspacing="0" border="0" align="center" style="margin: 0 auto; background-color: #FAF7F2;">` — 600px centered content column
- **Split column architecture:** Every section (§1–§7) is a `<tr>` containing:
  - `<td width="240" ...>` LEFT COLUMN — visual/data spine
  - `<td width="360" ...>` RIGHT COLUMN — headline + copy
  - These cells never have internal margins that reduce effective column width below the declared widths
- **Sole full-width exceptions:** Header band, gold rule bars, REMS panel, CTA section, Signature, ISI
- **Font stack:** `Arial, Helvetica, sans-serif` everywhere — no external font imports, no @import (brand rule)
- **CSS approach:** Inline styles on every element. `<style>` block in `<head>` contains ONLY:
  ```css
  body { margin: 0; padding: 0; background-color: #EDE8E0; }
  a { color: #4B2D8F; text-decoration: underline; }
  img { display: block; border: 0; }
  table { border-collapse: collapse; }
  ```
  No class-based layout rules. No external fonts. No CSS Grid. No Flexbox.
- **All images:** `[images_base64_N]` placeholder tokens. Every `<img>` carries `alt=""` descriptive text, `border="0"`, `style="display:block;"`.
