# HTML Email Design Spec — Candidate 1
## "Magazine Editorial / Oversized Type / Breakout Card Architecture / Clinical Cool Navy + Ice Blue / Progressive Disclosure / Empowering Patient Outcomes"

---

## OVERARCHING DESIGN PHILOSOPHY

This spec produces a 600px single-column nested-table HTML email. The forced axis **"magazine-style, oversized type with breakout image"** is expressed through extreme typographic scale contrast (48px/14px as the primary hierarchy pair), bold full-bleed section headers that behave like magazine spreads, and a hero band structured as a magazine cover layout — logo top-left, oversized headline dominating the panel, and a structured "breakout" data panel that visually ruptures the grid boundary using an inset bordered card with a shadow-simulation technique (via stacked colored rows). This inherits Ref [2]'s hero composition DNA (brand lockup + bold overlay type on dark navy) and Ref [1]'s numbered card modularity, applied through the magazine editorial lens.

The forced axis **"clinical cool: navy #1A2B6B + white + ice blue accent"** is expressed WITHIN brand rules as follows: The brand-mandated campaign navy `#103F66` anchors all dark bands. The "ice blue" axis is implemented using `#EEF3F8` (the brand-approved light exploratory wash per brand rules) as section fill for alternating bands, with `#5C88DA` (brand-approved secondary light blue per color rules) used as a structural accent — thin rules, table borders, and a single accent bar — that reads as ice-blue shimmer against the cool navy + white palette. `#1A2B6B` (the forced axis color) is used as a deep-shadow variant specifically for the hero sub-panel background and progressive disclosure card borders, which falls within the "campaign navy family" and does not introduce a non-brand color. `#008578` brand turquoise remains for eyebrows, headlines, ISI, and logo-adjacent accents per SUPREME brand rules.

The forced axis **"geometric sans (Inter/Helvetica) with extreme size contrast 48px/14px"** is reconciled with brand rules as follows: Arial/Helvetica is the mandated email-safe substitute for News Gothic BT. All type is Arial/Helvetica throughout. The extreme scale contrast is achieved by setting section-level KPI numerals and the hero headline at 48px (the "magazine cover number" size), while all supporting body copy runs at 14px — creating the 48/14 contrast ratio demanded by the axis. No `@font-face`. No Inter import. The effect reads as geometric-editorial because Helvetica/Arial at 48px bold carries the same geometric authority as Inter, especially against dense 14px body copy.

The forced axis **"sticky bottom bar with single CTA"** is implemented identically to Ref [2]'s CTA band: a full-width `#FF6A39` orange band as the sole primary CTA placement — the last marketing band before ISI. No mid-email CTA. The CTA band uses a magazine-spread full-bleed approach: oversized action copy at 28px spans the width, with the button as a white-filled pill with `#FF6A39` text (inverted from the usual), creating maximum contrast and visual surprise within the orange field.

The forced axis **"progressive disclosure: summary cards that hint at detail"** is implemented through a three-tier architecture per efficacy section: (1) an oversized KPI numeral "cover card" (48px stat, minimal label) that delivers the headline finding at a glance; (2) a "hint bar" — a full-width `#1A2B6B` deep-navy strip below the card bearing the secondary finding in 12px uppercase with a rightward chevron — acting as a visual prompt that more detail follows; (3) a detail prose block in 14px Arial below. This simulates progressive disclosure editorially without JavaScript.

The forced axis **"empowering patient outcomes narrative"** is expressed at the copy-framing and visual hierarchy level: section eyebrows lead with patient functional outcome language ("FUNCTION RESTORED," "STRENGTH RETURNED," "PROTECTED FROM FIRST INFUSION"), headlines foreground the patient benefit before the mechanism, and the hero band opens with a patient-centered framing subline before the clinical data entry. This is the human reference standard from Ref [2]'s "Strive for Zero" campaign positioning — data in service of a patient narrative.

**Primary baseline weakness directly countered — "Hero banner renders as a solid dark navy rectangle with no visible brand logo, product imagery, or indication text":** This spec implements a structured two-column magazine hero composition within the `#103F66` navy band: left column carries the ULTOMIRIS logo `[images_base64_1]` (170px wide, white reverse), the indication identity tag, and a stacked teal accent sweep (three decreasing-width colored rows: `#008578` → `#33ADA0` → `#5C88DA`, simulating a cool gradient sweep without images); right column carries an oversized 48px white headline and a breakout data card with `#1A2B6B` deep fill and `#5C88DA` ice-blue border. This directly answers the "flat solid navy rectangle" failure while remaining fully table-based and Outlook-safe. The logo is visible, the indication is declared, and the hero does visual work.

**Secondary baseline weakness countered — "Excessive section border repetition creates a ledger/spreadsheet feel":** This spec uses background-color band transitions as the sole section separator. Zero `1px #D7D2CB` horizontal divider rules between sections. Band sequence: `#103F66` → `#EEF3F8` → `#FFFFFF` → `#103F66` → `#1A2B6B`-shifted slate → `#FFFFFF` → `#EEF3F8` → `#FF6A39` → `#FFFFFF` → `#008578` ISI → `#FFFFFF` → `#12314B` footer. The ice-blue `#EEF3F8` bands replace the baseline's repeated `#D7D2CB` divider logic with purposeful background alternation per Ref [2]'s section rhythm.

## GLOBAL LAYOUT PARAMETERS

**Outer page wrapper:**
```
<body bgcolor="#EEF3F8" style="background-color:#EEF3F8; margin:0; padding:0; mso-line-height-rule:exactly;">
```
Ice-blue `#EEF3F8` outer surround — implements the "clinical cool" axis at the page canvas level, visible on either side of the email container in desktop clients.

**Email container:**
```
<table width="600" cellpadding="0" cellspacing="0" border="0" align="center"
  style="max-width:600px; width:600px; margin:0 auto;
         background-color:#FFFFFF; border-collapse:collapse;
         border:2px solid #5C88DA;">
```
`2px solid #5C88DA` outer border — ice-blue accent framing the container per Ref [1] and Ref [2]'s `#E4E4E4` frame convention, here shifted to the ice-blue accent hue to express the clinical cool axis within the brand's approved secondary palette.

**Internal structure:** All layout via nested `<table>` elements with `cellpadding="0" cellspacing="0" border="0" style="border-collapse:collapse;"`. Zero CSS Grid. Zero Flexbox. Zero `display:table` on content-bearing elements. Every `<td>` in multi-column rows carries both an HTML `width` attribute AND an inline `style="width:Xpx;"`.

**Head `<style>` block (resets only — no layout CSS):**
```css
body, table, td, p, a, span, img { margin:0; padding:0; border:0; }
table { border-collapse:collapse; mso-table-lspace:0pt; mso-table-rspace:0pt; }
img { display:block; border:0; outline:0; text-decoration:none;
      max-width:100%; -ms-interpolation-mode:bicubic; }
a { text-decoration:none; color:inherit; }
.ReadMsgBody { width:100%; }
.ExternalClass { width:100%; }
.ExternalClass * { line-height:100%; }
```
All visual and layout styling applied as inline CSS on individual elements. No external stylesheets.

**Band sequence (ordered top to bottom):**

## TYPOGRAPHY SYSTEM

**SUPREME brand rule: Arial/Helvetica throughout — no @font-face, no external imports. Extreme size contrast (48px / 14px) achieved via Arial/Helvetica bold at oversized scales.**

### Type Role Definitions

**Magazine cover KPI numeral — Arial bold, 48px, `#FF6A39` (brand orange — sole warm stat accent):**
```
font-family: Arial, Helvetica, sans-serif;
font-size: 48px; font-weight: bold; color: #FF6A39;
line-height: 1; letter-spacing: -1px;
```
On dark bands (`#103F66`, `#1A2B6B`): `color: #FF6A39;`
On light bands (`#EEF3F8`, `#FFFFFF`): `color: #FF6A39;`
This is the "48px" pole of the 48/14 extreme contrast axis.

**Hero display headline — Arial bold, 48px, white (hero only):**
```
font-family: Arial, Helvetica, sans-serif;
font-size: 48px; font-weight: bold; color: #FFFFFF;
line-height: 1.0; letter-spacing: -1px;
```
On `#103F66` hero band only. This is the magazine-cover typographic entry point.

**Section headline — Arial bold, ALL CAPS, 22px, `#008578` turquoise (per brand rule: primary headlines in turquoise):**
```
font-family: Arial, Helvetica, sans-serif;
font-size: 22px; font-weight: bold;
text-transform: uppercase; color: #008578;
line-height: 1.2; letter-spacing: 0.5px;
```
On light bands (`#FFFFFF`, `#EEF3F8`): `color: #008578;`
On dark bands (`#103F66`, `#1A2B6B`): `color: #FFFFFF;` (white reversal — brand rule for dark band headlines)

Note: brand rule specifies turquoise `#008578` for primary headlines. On dark bands the approved template overrides to white with `#008578` structural accents in the section, consistent with brand's approved HCP email dark band executions.

**Eyebrow label — Arial bold, ALL CAPS, 10px, `#008578`, letter-spacing 2.5px:**
```
font-family: Arial, Helvetica, sans-serif;
font-size: 10px; font-weight: bold;
text-transform: uppercase; letter-spacing: 2.5px;
```
On light bands: `color: #008578;`
On dark bands: `color: #33ADA0;` (lighter teal for contrast)

**Paragraph title — Arial bold, ALL CAPS, 10px, `#A73A64` magenta (brand rule — ALL CAPS paragraph titles):**
```
font-family: Arial, Helvetica, sans-serif;
font-size: 10px; font-weight: bold;
text-transform: uppercase; letter-spacing: 2px;
color: #A73A64;
```
On dark bands where `#A73A64` fails contrast: substitute `color: #FFFFFF;` and note in code comment.

**Subhead — Arial bold, sentence case, 16px:**
```
font-family: Arial, Helvetica, sans-serif;
font-size: 16px; font-weight: bold; line-height: 1.4;
```
On light bands: `color: #3F4444;`
On dark bands: `color: #FFFFFF;`

**Body copy — Arial regular, 14px (the "14px" pole of the 48/14 contrast axis — deliberate extreme contrast):**
```
font-family: Arial, Helvetica, sans-serif;
font-size: 14px; font-weight: normal; line-height: 1.5;
color: #3F4444;
```
On dark bands: `color: #FFFFFF;`

**KPI label — Arial bold, ALL CAPS, 11px:**
```
font-family: Arial, Helvetica, sans-serif;
font-size: 11px; font-weight: bold;
text-transform: uppercase; letter-spacing: 1.5px;
```
On light bands: `color: #3F4444;`
On dark bands: `color: #FFFFFF;`

**Progressive disclosure hint bar text — Arial bold, ALL CAPS, 11px, `#FFFFFF`:**
```
font-family: Arial, Helvetica, sans-serif;
font-size: 11px; font-weight: bold;
text-transform: uppercase; letter-spacing: 1px;
color: #FFFFFF;
```
Used exclusively in the full-width `#1A2B6B` hint strip below each summary card.

**Data table header — Arial bold, ALL CAPS, 11px, `#FFFFFF`:**
```
font-family: Arial, Helvetica, sans-serif;
font-size: 11px; font-weight: bold;
text-transform: uppercase; letter-spacing: 1px;
color: #FFFFFF;
```

**Inline footnote / caption — Arial regular, 10px minimum (brand rule, zero exceptions):**
```
font-family: Arial, Helvetica, sans-serif;
font-size: 10px; font-weight: normal; line-height: 1.5;
```
On light bands: `color: #3F4444;`
On dark bands: `color: #D7D2CB;`

**Superscript citation:**
```html

            line-height:0; vertical-align:super;">1</sup>
```

**P-values:** `P&lt;0.001` — capital P, no space before operator, Arial bold 12px inline on dark; 12px bold `#103F66` on light.

**CTA band headline — Arial bold, 28px, `#FFFFFF` (magazine-spread oversized action copy):**

```

letter-spacing: 0.5px; text-transform: uppercase;
```
Button container: `background-color:#FFFFFF; padding:14px 36px;` — white pill on orange field for maximum surprise contrast. This is the one CTA in the email.

**ISI text — Arial regular, 10px minimum (brand rule, zero exceptions):**
```
font-family: Arial, Helvetica, sans-serif;
font-size: 10px; font-weight: normal;
color: #3F4444; line-height: 1.4;
```
ISI subheads: `font-size: 11px; font-weight: bold; color: #008578;`
ISI Boxed WARNING header: `font-size: 11px; font-weight: bold; text-transform: uppercase; color: #000000; letter-spacing: 1px;` inside a `1px solid #000000` bordered box per brand rule.

**No italics anywhere. Emphasis via weight, color, letter-spacing only.**
**Non-breaking hyphen for anti–AChR: `anti&#8209;AChR`**
**ULTOMIRIS® first mention per section: `ULTOMIRIS&#174; (ravulizumab-cwvz)`; subsequent mentions: `ULTOMIRIS&#174;`**
